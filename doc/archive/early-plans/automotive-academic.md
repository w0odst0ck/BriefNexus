# 自动驾驶感知 — 照明影响研究（方案调研中）

> ⚠️ 此方向仍在方案调研阶段，未最终确定。以下内容为当前思路整理，会随调研推进持续更新。

## 核心问题

**照明条件如何影响自动驾驶感知系统？**

这不是一个空泛的问题。自动驾驶的视觉感知（摄像头、LiDAR）依赖环境光照：

```
晴天正午   vs   夜间城市     vs   对向远光灯     vs   隧道出入口
  ───→ 感知算法在不同光照条件下的精度退化曲线不同
```

而我们（BriefNexus）手里有**中国照明标准数据库**（430 条，含 85 条汽车照明），
这些标准定义了前照灯配光、信号灯光色、雾灯光束等参数——这正是光照环境的约束边界。

```
标准数据库 ─→ 光照参数表 ─→ 仿真场景生成 ─→ 感知算法评估
```

## 可行方向（候选，待收敛）

### 方向 1：远光灯/自适应前照灯对感知系统的干扰

```
问题: 对向车道车辆远光灯直射摄像头 → 过曝 → 目标丢失
      AFS (自适应前照灯系统) 弯道照明 → 光型变化 → 算法适应性

数据: GB 4599（前照灯配光性能）、GB/T 30036（自适应前照明系统）
       GB 21259（气体放电前照灯）、GB 25991（LED 前照灯）

思路:
  1. 从标准中提取配光曲线参数
  2. 在仿真环境中模拟不同前照灯工况
  3. 评估摄像头/LiDAR 在每种工况下的感知退化
```

### 方向 2：雨雾/低见度天气光照的感知补偿

```
问题: 雨雾天 + 低照度 → 摄像头对比度下降 → 检测召回率暴跌
      LED 自适应雾灯 / 红外补光 是否能补偿？

数据: GB 4660（前雾灯配光性能）、GB/T 24965.3（交通警示灯）
       非采标（雨雾相关环境试验标准）

思路:
  1. 雾灯配光参数 → 仿真雨雾光照场景
  2. 对比有/无雾灯辅助下的感知精度
  3. 量化分析：特定光照条件下感知算法失效边界
```

### 方向 3：信号灯/标志灯具 识别与交互

```
问题: 自动驾驶车辆需要识别前车的转向灯/制动灯信号
      前车灯光频闪/故障/非标 → 误判风险

数据: GB 4785（信号灯安装规定）、GB 5920（光信号装置配光）
       GB 17509（转向信号灯配光）、GB 15235（倒车灯）
       GB 18408（后牌照板照明）、GB 13954（特种车辆标志灯）

思路:
  1. 信号灯色度/光度参数 → 标准识别距离理论推演
  2. 不同天气/距离下信号灯被感知算法识别的可靠性
  3. 关键问题：自动驾驶何时能可靠检测到前车制动灯？
```

### 方向 4：行业标准 → 仿真参数映射方法论

```
问题: 如何从标准文本中自动化提取光照参数？
      LLM + 规则 → 结构化参数表 → 仿真场景

方法:
  1. 选取 5-10 个核心前照灯/信号灯标准
  2. 手工提取关键约束参数（配光/色温/照度/光型）
  3. 设计 JSON Schema
  4. 用 LLM 做批量参数提取，验证准确率

产出:
  - 标准→仿真参数映射的方法论论文
  - 开源参数提取工具
```

## 当前掌握的相关数据

| 数据类型 | 规模 | 状态 |
|---------|------|------|
| 前照灯标准（GB 4599 等） | 多个版本，覆盖 1994-2024 | 已有 PDF（4599-2024 有全文） |
| 信号灯标准（GB 5920 系列） | 覆盖 1999-2024 | 元数据已入库，需全文 |
| 雾灯标准（GB 4660 系列） | 覆盖 1994-2016 | 元数据已入库 |
| 自适应前照灯（GB/T 30036） | 2013 版 | 元数据已入库 |
| 摩托车/特殊车辆照明 | ~30 条 | 已入库（automotive_lighting sector） |
| 环境耐久性（GB/T 10485） | 覆盖 1989-2025 | 已有 PDF |

**关键缺失**：国内采标类标准大多无全文（openstd 通道已死）。需评估是否需要付费购买特定标准的全文，或改用国际标准（ECE R48、R112）进行参数对照。

## 实验路径设计（确定方案后执行）

**核心逻辑**：430 条照明标准不是用来存放的，是用来定义光照条件的。用 GB 标准定义的参数边界去挑战感知算法。

在现有开源成果（AV-perception-benchmark-Carla）基础上，用自己的标准数据做增量贡献。

### 所依赖的开源基石

| 项目 | 用途 |
|------|------|
| `github.com/Michael-ola/AV-perception-benchmark-Carla` | Carla YOLOv8/DETR 多天气行人检测框架 |
| `github.com/DriveMindLab/DarkDriving-ICRA-2026` | 9538 对日/夜真实场景数据集（ICRA 2026） |
| `github.com/KevinLADLee/carla_dataset_tools` | Carla 多传感器数据采集管道 |

### Phase 0：环境搭建（1-2 天）

```
目标: 跑通 AV-perception-benchmark-Carla

[ ] Clone repo + 安装 Carla 0.9.15
[ ] Python 依赖: ultralytics + torch + carla
[ ] 跑 Clear Noon 基线 → 记录 mAP
[ ] 跑 Night → 确认光照变化后的 mAP 退化

产出: 可复现的基线数字
```

### Phase 1：标准参数提取（3-5 天）

**这是核心差距——别人没有的环节**。从已有 PDF + 元数据中提取关键光照参数：

```
优先级: 提取对感知影响最大的 5-8 个标准

P0 — GB 4599-2024  前照灯 → 远光/近光配光曲线、照度阈值
P0 — GB 4785-2019  信号灯 → 制动灯/转向灯/倒车灯光色+光度
P1 — GB 25991      LED前照灯 → 色温范围、配光
P1 — GB 4660       前雾灯 → 配光、截止线
P1 — GB 5920       光信号装置 → 信号灯配光分布
P2 — GB/T 30036    自适应前照明 → AFS 弯道光型
P2 — GB 13954      特种车辆标志灯 → 警示灯频闪

方法: PDF → pdfplumber 提取 → LLM 填入结构化模板 → JSON

产出: gb_lighting_parameters.json
```

### Phase 2：Carla 光照条件映射（2 天）

把 GB 参数映射为 Carla 可表达的光照配置：

| 标准条件 | Carla 配置 | 对比组 |
|---------|-----------|--------|
| GB 远光灯合规 | `sun_altitude=-90` + `VehicleLightState.HighBeam` | 无照明 |
| GB 近光灯合规 | `sun_altitude=-90` + `VehicleLightState.LowBeam` | 远光 vs 近光 |
| GB 前雾灯合规 | `sun_altitude=-90, fog_density=50` + 雾灯 | 有雾无雾灯 |
| GB 信号灯感知距离 | 不同距离放置信号灯检测 | 50m/100m/150m |
| GB 日间行车灯 | `sun_altitude=45, cloudiness=0` + DRL | 无 DRL |

**精度判断**：如果 Carla API 的光照差异已足够显著 → 直接 Phase 3。
如果不够 → 进 UE Editor 导入 IES 光型文件做配光曲线级仿真。

### Phase 3：实验矩阵（3-5 天）

```
模型: YOLOv8 / DETR / Faster R-CNN
任务: 行人检测 + 车辆检测
场景: 直道对向行驶

自变量（光照）:                 因变量（精度）:
  ┌──────────────┐              ┌───────────────┐
  │ 无照明(baseline)│             │ mAP@0.5      │
  │ 近光灯合规    │              │ Recall        │
  │ 远光灯合规    ├─────────────→│ Precision     │
  │ 远光灯超标    │              │ 置信度分布    │
  │ 雾灯+雾      │              │ 退化率        │
  │ 对向眩光     │              └───────────────┘
  └──────────────┘

每次: 固定场景 + 固定目标位置 + 仅变换光照 → >=500帧/条件
```

**最小可行实验（第一个比较）**：

```
实验 A: 夜间对向无车（仅环境光） → baseline
实验 B: 夜间对向合规近光灯       → 影响？
实验 C: 夜间对向合规远光灯       → 影响？
实验 D: 夜间对向违规远光（超标） → 影响？

→ 输出: 对向灯光照条件→感知精度退化曲线
→ 贡献: 用 GB 标准定义"合规"和"违规"的分界

### Phase 4：分析 + 输出（2-3 天）

**定量产出**：

```
1. 光照条件 → mAP 退化曲线（图）
2. 每类光照下的 Recall 矩阵（表）
3. "合规光照"区间（感知算法能接受的 GB 参数范围）
4. 对比: Carla 默认光照 vs GB 合规光照 vs GB 违规光照
```

**定性产出**：

```
1. 失效模式分析：什么光照条件下感知彻底崩溃？
2. 关键参数识别：哪些 GB 参数对感知影响最大？
3. "合规"不等价于"可感知"——标准参数区间是否适用于自动驾驶感知？
```

**可能的论文论点**：

> 中国汽车照明国标（GB 4599/4785）定义的合规光照参数，在当前主流视觉感知模型（YOLOv8/DETR）的夜间鲁棒性评估中，合规与违规之间的mAP差异达到 X%，且标准中的某些合规区间对于自动驾驶感知而言仍属高风险。
