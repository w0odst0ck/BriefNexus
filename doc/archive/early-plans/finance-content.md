# 金融内容线 — 情报 → 内容 → 流量 → 变现

## 定位

利用 intel 情报采集能力，生成高质量财经/投资内容，发布到公域平台获取流量。

**核心逻辑**：数据独特性 × 分析深度 → 内容壁垒 → 信任 → 流量 → 变现。

## 模型支撑（与数学建模线的关系）

金融简报中的分析深度取决于 NLP 模型质量。

| 简报段落 | 模型输入 | 模型输出 | 依赖 |
|---------|---------|---------|------|
| 关键信号 | 白宫/EU/Fed 声明原文 | 情感分数 (-1~1) + 主题标签 | 情感打分模型 |
| 行业热点 | GNW/NVIDIA 标题+摘要 | 影响力评分 (0~100) + 排序 | 影响力排序模型 |
| 合规动态 | SEC 8-K 全文 | 风险分类 + 摘要 | LLM 零样本分类 |
| 观点（短期） | 全部 intel 产出 + 情感分数 | 总结性判断 | LLM 模板填充 |

**当前状态**：以上模型均未实现（v0 版本可直接用 LLM + 规则模板替代）。

详见 `plan/math-modeling.md` 路线 A。

### 每日简报（750-1500 字）

> 建议首发平台：小红书 / 知乎

结构：
1. **今日关键信号**（1-2 条，来自 Fed/央行/白宫）
2. **行业热点**（1-2 条，GNW/NVIDIA）
3. **合规动态**（SEC 8-K 中值得注意的事）
4. **一句话观点**（如果模型成熟了）

### 周度深度（3000-5000 字）

> 建议平台：知乎 / 公众号

结构：
1. 本周宏观趋势总结
2. 重点事件拆解（如 Fed 会议纪要）
3. 数据驱动分析（需建模产出）
4. 投资启示

### 事件驱动（实时）

- 突发政策/财报 → 快速解读
- 配合 LLM 做多空/影响评分

## 技术实现

### intel 输出层封装

```bash
# 当前架构
python -m intel.main crawl          # 采集
python -m intel.main export         # 导出到 MD

# 需要新增
python -m intel.main publish        # 自动生成发布内容
  --platform zhihu|xhs|wechat       # 适配不同平台格式
  --style brief|deep|flash          # 内容形态
  --model deepseek                  # LLM 生成引擎
```

### 格式适配

| 平台 | 格式限制 | 适配要点 |
|------|----------|----------|
| 小红书 | 1000 字以内 | 短平快，emoji 分段 |
| 知乎 | 不限 | 长文结构，可带数据 |
| 公众号 | 不限 | 排版精美，图文并茂 |
| Twitter/X | 单条 4000 字 | 可开 thread |

## 变现路径

```
1. 冷启动（1-2 月）  → 0 -> 1000 粉丝
   纯内容，不植入广告，建立信任

2. 成长期（3-6 月）  → 1000 -> 1万 粉丝
   付费订阅试水（知识星球 / 爱发电）
   或接软广（券商/金融工具）

3. 成熟期（6月+）    → 1万+ 粉丝
   自营服务（投资建议 / 数据 API）
   或课程（如何做情报分析）
```

## 评估指标

| 指标 | 第 2 周目标 | 第 4 周目标 | 说明 |
|------|------------|------------|------|
| 发布频次 | 至少 3 篇 | 每天 1 篇 | 内容产出稳定性 |
| 单篇阅读 | >50 | >200 | 平台算法验证 |
| 粉丝增长 | >20 | >100 | 关注转化 |
| 互动率 | >2% | >5% | 点赞/评论/收藏 |

**第 2 周评估**：如果三篇内容均 <50 阅读 → 反思话题/平台/风格，必要时 pivot。
