# 数学建模 — 核心引擎

## 定位

数学建模不是独立项目，而是**嵌入到金融输出和标准数据库两条线的底层分析引擎**。

```
NLP 模型 ──→ 金融输出（情感指数、简报生成）
标准模型 ──→ 标准库（聚类、推荐、合规分析）
仿真模型 ──→ 学术产出（自动驾驶感知环境的照明影响）
```

---

## 两条建模路线

### 路线 A：金融内容支撑（Phase A — 数据就绪）

此路线是为 `plan/finance-content.md` 服务的。intel 采集的国际情报（白宫/EU/美联储/NVIDIA/SEC）已经在线，模型直接将原始文本转化为可消费的结构化产出。

#### A1：政策情感打分

```
输入: intel 采集的白宫公告 / EU 声明 / 美联储声明
方法: LLM 零样本情感标注 → 轻量分类器（DistilBERT / XGBoost）
输出: 每日情感指数 (-1.0 ~ 1.0) + 驱动事件原文
对接金融: 直接嵌入每日简报的"关键信号"段落
数据: 已就绪（WH/EU/Fed 日更文本）
```

#### A2：新闻影响力排序

```
输入: SEC 8-K / GlobeNewswire 企业公告
方法: 来源权重 × 时效衰减 × 关键词命中 综合评分
输出: 每日 Top-N 值得关注事件
对接金融: "今日看点"段落
数据: 已就绪（SEC/GNW 日更）
```

#### A3：自动摘要 + 简报生成

```
输入: 全部 intel 采集 + 模型产出（情感分 + 事件排名）
方法: LLM 模板填充 + 规则格式化
输出: 每日简报 MD 文本 → 小红书/知乎适配
数据: 全就绪，无独立模型也可用 LLM 直出
```

**A1/A2 依赖关系**：先 A1（情感打分，单一模型见效快），再 A2（多源综合评分），A3（LLM 模板输出，可提前启动手工模板版）。

#### 产出物清单

- [ ] 日频政策情感指数（线图 + 驱动事件原文）
- [ ] 每日简报自动生成器（情感分 + Top 事件）
- [ ] 可选：情感指数周度走势图（知乎配图）

### 路线 B：汽车感知仿真（Phase B — 需调研规划）

此路线是新的学术方向，核心问题：**照明条件如何影响自动驾驶感知系统**。

详见 `plan/automotive-academic.md`。此处仅列建模层面的依赖：

```
B1: 照明标准 → 结构化的光照参数表（色温/照度/配光分布等）
B2: 自动驾驶感知仿真环境建模（Carla/SUMO + 光照条件注入）
B3: 照明条件变化对感知算法的影响评估（mAP 退化曲线）
B4: 合规约束→仿真场景自动生成
```

该路线技术上依赖较多，先以调研和方案文档为主，统一方案后再开工。

---

## 技术栈

| 领域 | 推荐 | 理由 |
|------|------|------|
| 文本向量化 | `sentence-transformers` | 中文嵌入质量好 |
| 分类/回归 | `scikit-learn` / `XGBoost` | 轻量、可解释 |
| 深度学习 | `PyTorch` + `transformers` | 按需上 |
| 时序 | `statsmodels` / `prophet` | 经典、易用 |
| 仿真 | Carla / SUMO | 开源自动驾驶仿真 |
| 可视化 | `matplotlib` + `plotly` | 演示/论文插图 |

## 推荐推进顺序

```
Phase A 先跑（金融方向，数据就绪，快速验证）
   ↓ （A 跑起来后再并行调研 B）
Phase B 调研（自动驾驶 + 照明，方案未定，先搞懂再动手）
```

### Phase A 时间线（预估 2 周）

```
第1周: A1 政策情感打分（sentence-transformers + 分类器）
第1周: 简报 LLM 模板（简易版，规则填充，不依赖情感模型）
第2周: A2 新闻影响力排序（多源加权评分）
第2周: 全流程串联（采集→模型→简报→输出）
```

### Phase B 时间线（方案已定，参考 automotive-academic.md）

实验路径已写入 `plan/automotive-academic.md`，共 4 个 Phase + 时间线：

```
Phase 0: 环境搭建（Carla + benchmark 跑通）       — 1-2天
Phase 1: 标准参数提取（GB→光照参数 JSON）          — 3-5天
Phase 2: Carla 光照条件映射（GB参数→仿真配置）     — 2天
Phase 3: 实验矩阵（夜间/雨雾/眩光三组实验）        — 3-5天
Phase 4: 分析+输出（曲线/表格/论文骨架）           — 2-3天
```

详见 `plan/automotive-academic.md` → 实验路径设计。

## 决策点

| 决策 | 触发条件 | 选择 |
|------|---------|------|
| Phase A 是否继续投 | 2 周后评估金融内容反馈 | 继续/减投/pivot |
| Phase B 是否启动 | Phase A 稳定后 / 硬件就绪 | 启动/搁置（方案已定） |
| 技术选型（sim vs real） | 仿真 vs 真实数据集 | 取决于调研结论 |
