## 一、四套引擎

| 引擎 | 端口 | 能力 | 实测状态 |

## 三、RSSHub 路由

- **已接入 12 条**（`research-collectors/sources.yaml`，全 `mode: manual`）
- **实测可用未接入 22 条**，重点：`wallstreetcn/live`(100条/0.3s)、`yicai/brief`(50/0.2s)、`cls/depth`(32)、`caixin/latest`(20)、`infoq/recommend`(30)、`solidot/main`(20)、`openai/news`(10)、`huggingface/blog-community`(20)
- **实测不可用 13 条**：`anthropic/news`、`ithome/*`、`xueqiu/hots`、`cnbeta/*`、`v2ex/index`、`producthunt/today` 等（503/404）
- ⚠️ `bilibili/user/dynamic` 需 RSSHub 装 chromium 1228（已装，`patchright install chromium-headless-shell`）；且**每条只渲染首图**，多图会漏

## 五、真缺口

| 缺口 | 影响 |
|---|---|
| **无 `HTML_SPEC`** | 加 HTML 源仍要手写 100 行 |
| **渲染无池化** | 每请求 launch+close，2-17s |
| **代理未接** | 境外源直连（白宫/EU/NVIDIA 靠运气） |
| **无正文抽取** | trafilatura/lxml 未装，`summary` 仅 5/9 源有 |
| **X / Instagram 无通道** | MediaCrawler 不支持，RSSHub 需 token；gallery-dl 需 cookie |
| **图集能力** | 仅 gallery-dl 可补（方案属 `research-collectors` 仓） |

---

## 六、判定规则（选源时用）

1. RSSHub 有路由 → 加配置（不写代码）
2. RSSHub 没有 + 静态页 → BriefNexus 内置/外挂采集器
3. 需登录的国内社媒 → MediaCrawler
4. 境外图集（X/IG） → gallery-dl + cookie
5. 文档全文 → MinerU
