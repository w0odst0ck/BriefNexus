# 调研工具箱 — 平台能力扩展规划

> 2026-08-15 ｜ 目标：BriefNexus 从「单一页面抓取」进化为「多能力采集处理平台」
> 原则：**能力先行，数据源是能力的实例**——建好能力层，加源 = 加配置（非写代码）
> 现状：页面抓取（BaseCollector）+ 内存存储 + 拉取/回调；采集器 9 内置 + 5 挂载

---

## 一、能力矩阵（三层）

### C1 采集能力层（怎么拿到数据）

| 能力 | 现状 | 目标 | 参考（工具箱） |
|:--|:--|:--|:--|
| 静态页面抓取 | ✅ BaseCollector | 保持（内置范式） | 内置 9 源 |
| **RSS/Atom 订阅** | ❌ 无标准基类 | `RSSCollector` 抽象基类（配置驱动：url/解析/域），一个基类吃全部 RSS 源 | RSSHub 路由生态 |
| **JSON API 适配** | ⚠️ arxiv 特例 | `APICollector` 基类（auth/分页/字段映射） | arxiv 范式 |
| **浏览器渲染** | ❌ | CDP 渲染执行器（JS 渲染/反爬绕行），采集器可声明 `render: true` | chrome-devtools-mcp、page-agent |
| **登录态会话** | ❌ | 会话/cookie 池管理（登录型源） | mediacrawler |
| **文档/PDF 解析** | ❌ | 文档解析器（PDF/office → 文本 → NewsItem） | mineru |
| **变更监控** | ⚠️ mojin 快照 diff（专用） | 通用页面快照 diff 能力（任意源启用 `watch: true` → 变化可推送） | changedetection.io |

### C2 处理能力层（拿到后怎么加工）

| 能力 | 现状 | 目标 |
|:--|:--|:--|
| 去重 | ✅ 单任务内 | 保持 |
| 分类 | ⚠️ 关键词规则不全 | 规则补全 + 可选 LLM 分类 |
| **LLM 增强** | ⚠️ run --llm 雏形 | 摘要/翻译/实体抽取（DeepSeek） |
| 全文索引 | ❌（零持久化哲学） | 拉取侧索引（FTS/向量），平台不落盘 |

### C3 交付能力层（怎么给用户）

| 能力 | 现状 | 目标 |
|:--|:--|:--|
| 报告 | ✅ md/json | 模板化（按项目定制） |
| **变更预警推送** | ❌ | 快照 diff 触发 → 飞书/邮件（feishu_push.py 复用） |
| **调度** | ⚠️ 手动/快照 | cron 化（command payload，沿用 trade-pulse 经验） |
| 订阅回调 | ✅ webhook | 保持 |

## 二、落地路径（能力优先，3 批）

**第一批 P0：采集基类族（能力地基，1-2 天）**
1. `RSSCollector` 基类（feedparser，配置驱动：url/domains/sector/limit）——**建一次，加源=加配置**
2. `APICollector` 基类（requests + auth/分页/字段映射）
3. 基类 + 2 个实例验证（如 HuggingFace RSS + arXiv API 扩展）
4. 单元测试 + 挂载 + pull 管线适配

**第二批 P1：渲染 + 变更能力（1 周）**
5. CDP 渲染执行器（声明式 `render: true` 的采集器走浏览器渲染）——WAF/JS 源通用解法
6. 通用变更监控：快照 diff 抽象化（mjin 专用 → 平台通用能力）
7. 变更预警推送（diff 触发 → feishu_push.py）

**第三批 P2：文档解析 + LLM 处理（按需）**
8. 文档解析器（mineru/pdfplumber 集成）
9. LLM 增强管线（分类补全/摘要/翻译）
10. 调度 cron 化

---

## 三、能力落地后的收益（对比现状）

| 场景 | 现状 | 能力落地后 |
|:--|:--|:--|
| 加 10 个 RSS 源 | 写 10 个采集器 | **加 10 行配置**（RSSCollector 实例） |
| JS 渲染/反爬源（BOSS/巨潮/东财） | 无法采集 | CDP 执行器统一解决 |
| 合规/价格盯梢 | 专用脚本 | **任意源 `watch: true`** → 通用变更预警 |
| PDF 标准/政策 | 无法入 NewsItem | 文档解析器 → 全文检索 |
| 巡检 | ✅ check 子命令（今晚交付） | 保持 + 调度化 |
